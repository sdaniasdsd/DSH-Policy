# DSH 策略版宣传视频设计

[English](2026-10-12-dsh-policy-promo-video-design.md) | 中文

## 受众与目的

制作一条三分钟中文视频，向潜在用户介绍独立维护的 DSH 策略版。让观众理解策略层为 DSH 增加了什么，并引导他们查看项目仓库。

## 推荐创意

用一个开发任务贯穿视频，从输入需求讲到任务结果。展示策略层如何选择合适的工作流、把任务安排为多个阶段，并在原版 DSH agent loop 执行子任务时展示策略与进度信息。示例采用谨慎流程：先并行执行两项只读检查，再开始实施。

这个方向先呈现用户熟悉的问题，再用连续场景演示产品。逐项罗列功能会覆盖更多设置，但容易像功能清单；从架构开始讲解更准确，却需要观众预先了解更多背景。

## 叙事与时长

目标片长为三分钟，解说词约 700–950 个中文字，拆成 24–32 个解说节拍与画面镜头。内容依次包括：

1. 复杂请求通常包含多个步骤。
2. DSH 策略版在原版 DSH 执行循环前增加任务策略层。
3. 策略层选择或接受工作流，并将任务安排为有序阶段；同一阶段内的任务可在配置上限内并行执行。
4. 原版 DSH agent loop 执行子任务；用户可查看阶段进度与结果。
5. 界面展示所选策略与子任务 Token 场景估算。
6. 结尾说明项目是独立维护的实验性 fork，并引导观众访问 GitHub 仓库。

全片使用同一个开发场景。讲解应面向用户并以画面呈现；对于潜在用户判断是否了解项目没有帮助的 API 与实现细节不进入解说。

## 视觉与配音

采用讲解视频技能的代码绘制动效：黑色画布与星点背景、白色线稿、紫色重点、大字号中文、解说字幕、章节进度条和简洁 HUD。每个镜头只有一个主要视觉主体，并保持连续动作。解说使用中文；文案定稿后再用本地或云端 TTS 合成。先提供开头 30 秒样片，单独确认视觉风格、字号、配音语速和节奏。

## 事实与表达约束

- 说明项目是独立维护的实验性 fork，不是 DeepSeek 官方发行版。
- 准确说明策略层负责组织和分发工作，子任务由原版 DSH agent loop 执行。
- 将 Token 数称为场景估算，不称为账单金额或执行硬上限。
- 不暗示估算能证明节省成本、模型轮次完成就代表结果正确，或策略层会增加权限与文件系统隔离。
- 不承诺工作流持久恢复、自动重试或稳定商业支持。
- 画面中的数字、术语与产品主张都必须能在调研记录及其一手来源 URL 中找到依据。

一手来源：[项目 README](https://github.com/sdaniasdsd/dsh-change)、[策略包 README](https://github.com/sdaniasdsd/dsh-change/blob/main/packages/experimental/task-strategy/README.zh.md)和[默认入口指南](https://github.com/sdaniasdsd/dsh-change/blob/main/docs/upgrade-guide/v0.2.0-rc.2/task-strategy-default-entry/guide.zh.md)。

## 交付物与评审点

在 `DSH策略版宣传视频/` 下创建独立 Remotion 项目，与 DSH 源码仓库分开。交付可编辑项目、已确认的解说词与调研记录、渲染后的 MP4，以及简短交付说明。配音合成前先确认解说词；完成其余镜头组前，先确认开头 30 秒样片。交付前运行项目类型、渲染、动作密度和事实主张检查。

## 完成标准

- 解说词经确认，适合约三分钟片长，并贯穿同一个示例。
- 成片准确介绍项目，清楚区分其与 DeepSeek 官方发行版，并包含 GitHub 仓库引导。
- 画面遵循选定的动效方向，字幕清楚可读，并通过讲解视频流程中的动作与事实检查。
- 交付目录包含可编辑源码、事实来源、已确认文案、成片和遗留限制说明。
