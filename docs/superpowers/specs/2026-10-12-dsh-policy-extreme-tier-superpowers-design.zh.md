# DSH 策略版极端高档与 Superpowers 风格插件设计

[English](2026-10-12-dsh-policy-extreme-tier-superpowers-design.md) | 中文

## 目标

为可选任务策略工作流库中的 Codex 风格、Claude 风格和 ZCode 风格策略增加 `extreme-high` 档，并新增可卸载的 Superpowers 风格策略插件。本次改动用于 DSH 策略版的高强度工作流验证，不声称增加了实测或计费的提供方用量。

## 现有边界

任务策略包已将 DSH 执行的风格策略（`codex-style`、`claude-style`、`zcode-style`）与原生 Codex 和 Claude 编排适配器（`codex` 和 `claude`）分开。风格策略通过配置的 DSH preset 执行规划、工作、复核、修订和产物检查；原生适配器调用一次原版子代理提供方并返回最终结果。本设计扩展 DSH 执行的风格策略，不改变原生提供方的生命周期或身份验证。

## 推荐设计

为 Codex 风格、Claude 风格、ZCode 风格和新的 Superpowers 风格插件增加 `extreme-high` 档。它使用独立且有界的配置档，其节点数、修订次数、单步 Token 和超时上限均高于现有 `high` 档。默认值仍受现有 schema 最大值约束；所有捕获的配置都经过校验，并反映在基线与最大场景估算中。现有低、中、高档行为保持不变。

Codex 风格策略保留串行工作与逐节点只读复核，并使用极端高档更大的规划和修订上限。Claude 风格策略保留只读探索和最终复核，并使用相同的更高上限。ZCode 风格保留现有里程碑执行模式并使用更高上限。三者继续遵循现有产物检查语义；只根据工具确认的失败或带文件证据的复核问题执行修订。

新增可独立挂载的 `plugins/superpowers-style` 入口，使用现有 style-policy 机制和原版 DSH preset/执行器。其工作流分为理解任务、有界规划、实施、验证、复核和基于证据的修订阶段。它采用可识别的 Superpowers 工作节奏，但不导入或执行外部技能文件、不调用原生 Codex/Claude，也不宣称是官方 Superpowers 集成。它支持与现有三个风格插件相同的四档和 Token 估算说明。

更新编排选择器和策略目录，使用户可以选择新策略及其档位。四个新增或扩展的风格插件都保持可选；不改变 profile 默认配置。保留现有插件 ID、包入口、策略 ID 和运行捕获行为。

## 配置与用量核算

极端高档配置提供经过校验的有限值：最大计划节点数、修订次数、单步输出 Token 和超时。其默认值须高于对应的高档默认限制，并保持在包级最大值内。现有 Token 成本假设仍是可编辑场景输入，不称为硬上限或账单金额。报告继续区分场景估算和实际观测到的子任务用量；无法取得的提供方用量标为未知。

编排选择器为 Codex 风格、Claude 风格、ZCode 风格和 Superpowers 风格模式显示极端高档。任务接单时捕获所选档位及限制，后续配置变化只影响新任务。

## 失败与安全行为

格式错误或不支持的档位偏好在策略选择时失败。超出捕获节点限制的计划在准入超额工作前失败。每个子任务步骤继续使用现有取消、超时、任务结果、DSH 权限和清理行为。修订次数保持有界；结果未知的执行不会重放。新插件不扩大工具权限、不改变文件系统隔离、不自动批准操作，也不创建提供方凭据。

## 验证范围

针对性包测试覆盖档位解析、捕获限制、阶段与修订上限提升、场景估算、选择器可见性、插件释放、基于证据的修订、取消，以及低/中/高档行为不变。真实 Loader 组合测试确认各可选插件能在真实任务策略载体中注册并卸载。受控高强度运行使用确定性子任务结果，在不需要提供方凭据的情况下覆盖最大配置计划和修订路径。真实 Codex/Claude API 或订阅用量属于另行手动选择的检查，不是本次改动的必要条件。

## 不在范围内

- 更改原生 `plugins/codex` 或 `plugins/claude` 编排、身份验证或提供方运行生命周期。
- 为通用工作流目录增加极端高档。
- 自动消耗真实 Codex/Claude 配额、估算实际账单或承诺实测用量目标。
- 加载第三方 Superpowers 技能文件，或将本插件描述为官方集成。
- 更改已发布 profile 默认值或基础产品组合。

## 完成标准

- Codex 风格、Claude 风格、ZCode 风格和 Superpowers 风格提供有界的 `extreme-high` 档，其成本场景反映已捕获的限制。
- Superpowers 风格插件可卸载，且仅通过 DSH 现有任务运行时和 preset 执行。
- 现有低、中、高档、原生 Codex/Claude 适配器及默认组合保持现有行为。
- 针对性确定性测试与真实组合证据覆盖注册、执行限制、清理、估算和选择器行为。
