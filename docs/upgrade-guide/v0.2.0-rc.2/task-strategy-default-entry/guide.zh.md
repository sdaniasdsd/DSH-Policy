# 任务策略默认入口

[English](guide.md) | 中文

## 变更

可选载体增加 `entry.enabled`，默认关闭。策略版工作流 bundle 默认开启， 现有 profile 的显式覆盖仍优先。插件页通过原有版本化配置表单保存此开关。 普通根用户输入在根模型步骤前分类。工具工作使用原有策略提交及所属 Jobs； 根执行工具同时受到展示过滤和执行检查。路由或选择失败不会退回直接执行。

`task-strategy/entry` 记录原始输入、请求身份及展示状态。 `task-strategy-entry` 消息来源标记提供给模型的宿主事实。 快照只保留计数，不重复子任务结果正文；原版 Jobs 保留结果。 路由和选择复用已配置的选择模型路由与限额。 文本补充在下一尚未开始阶段读取；非文本执行输入明确失败，原始附件仍有记录。

## 迁移

1. 设置 `entry.enabled: true` 开启自动路由，false 保留显式派发。 开关作用于未来输入，不改变已接收 Jobs。
2. 从目录读取 `entryEnabled`，通过 `entryState({ sessionId })` 读取活跃状态。 取消、切换和继续要求所属请求身份；切换与继续还要求已观察到的绑定版本。 无活跃 owner 时返回空入口状态。恢复的卡片显示已中断，不重新执行。
3. 构建匹配的 Host、生成 Remote 与 Client 产物。新会话日志应继续使用本版本， 旧读取器可能拒绝新必需事件类型；不要删除事件使旧二进制读取日志。
4. 将展示成本视为子任务场景估算；路由、选择、根模型、实际工具历史和推理用量 不属于该估算。
