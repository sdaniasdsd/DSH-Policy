# Contributing

English | [中文](CONTRIBUTING.zh.md)

Thank you for your interest in contributing to this independent DeepSeek Harness policy fork.

The project is under active development. Issues and focused pull requests are welcome. Before starting a large change, open an issue to discuss the proposed behavior and its fit with the project.

## Before you contribute

- Search the [issue tracker](https://github.com/sdaniasdsd/DSH-Policy/issues) for related reports or proposals.
- Keep each pull request focused and explain the user-visible behavior or bug it changes.
- Add or update tests for behavior changes, and run the relevant checks described in the repository development documentation.
- Update both English and Chinese documentation when changing maintained user-facing docs.
- Include reproduction steps, test output, screenshots, or logs when they help reviewers verify the change. Remove secrets and personal data.
- Open a pull request against main and summarize the change, validation, and any known limitations.

You can also report bugs, improve documentation, build plugins, write guides, and help answer community questions. Add the [dsh-plugin](https://github.com/topics/dsh-plugin) topic to a plugin repository to help developers discover it.

This repository is an independent experimental fork, not the official DeepSeek Harness project. Please direct upstream-specific changes to the upstream repository.

Thank you for helping improve the project and its ecosystem.
