# AGENTS.md — Agent Notes

Agent Notes are effectively RFCs written by agents: durable proposals and decision records that preserve rationale, alternatives, consequences, and required verification. Follow the [documentation standard](../../docs/AGENTS.md) and the [Agent Note rules](README.md).

**Every new Agent Note triggers a supersession check.** Search the active tree for existing notes covering the same decision or mechanism. Consolidate fully superseded notes when the current owner preserves all useful rationale; keep partial supersessions active and cross-linked.
