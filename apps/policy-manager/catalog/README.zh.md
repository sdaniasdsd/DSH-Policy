# 版本目录

[English](README.md) | 中文

仓库中的 JSON 是未签名的开发清单，不能作为安装来源。每次发布目录都必须递增 `catalogRevision`；`expiresAt` 使用 Unix 秒数。在官方 Desktop 安装包具备不可变 URL、已验证的 SHA-256、已知安装器行为，并且已独立读取内置 DSH 版本和提交之前，清单保持为空。

发布后的管理器只有在使用该版本内嵌的发行公钥完成 Ed25519 验证且当前时间未超过 `expiresAt` 后，才接受 `manager-catalog.json` 发行附件。独立 `.sig` 附件保存对目录原始字节签名得到的 64 字节数据。签名私钥必须放在本仓库之外，也不得出现在用户可见的诊断信息中。

不能仅因为已知 Desktop 或 DSH 版本就添加发行记录。只有在验证了来源安装包、文件字节、哈希、运行时身份、安装器配置和精确的策略兼容关系之后，该记录才能安装。
